# 上達部

> 帝の問いに対し、私情を交えず実務的な奏上を返す、朝議参加中の上級貴族集団。（ch000-sc10）

## 1. Core Identity
本項目は個人ではなく、**「朝議に参与する上級貴族集団」**として観測される存在である。（ch000-sc10）
その中核的な駆動は、帝の問いに対して朝議の秩序にかなう**簡潔で公的な回答を返すこと**にある。（ch000-sc10）
現時点で確認できる役割は、帝の前で議に与り、天に近い山について**駿河の國の山を奏上する**実務担当である。（ch000-sc10）

## 2. Personality Model

### 2.1 Core Values
- **実務性**：帝の問いに対し、地理的対象を具体的に示して答えている。「天に近い山」という抽象的な問いを、**「駿河の國にある山」**という実務的回答に落としている。（ch000-sc10）
- **君命順守**：感情的反応ではなく、帝への**服従的で厳粛な奏上**を行う。（ch000-sc10）
- **簡潔な公性**：発話は「奏上らしい簡潔で公的な言い方」であり、不要な枝葉や私情を付けない。（ch000-sc10）
- **曖昧さの回避**：抽出メモ上も「曖昧な返答をすることをしなかった」と整理されており、判断保留より明確化を選ぶ。（ch000-sc10）

### 2.2 Motivations & Desires
- **Surface desire:** 帝の問いに対して、意図に沿う**実務的な答えを返すこと**。（ch000-sc10）
- **Deep desire:** 明言はないため不明。だが行動上は、朝議の場を乱さず、**臣下として適切に機能すること**を優先しているように見える。（ch000-sc10）
- **Ultimate desire:** 資料不足のため不明。単独場面のみでは、長期的な人生目標や集団としての究極目的は確定できない。

### 2.3 Core Fears & Avoidances
最も明確に避けているのは、**曖昧で役に立たない返答**である。（ch000-sc10）
また、観測場面では帝の問いの背後にある私的意味へ踏み込まず、**問われた実務範囲に限定して応答する**。（ch000-sc10）
このことから、公的場面での不適切さ、あるいは臣下としての役割逸脱を避ける傾向がうかがえる。（ch000-sc10）

### 2.4 Character Traits
- **Public persona:** 厳粛で、礼を失わず、必要な情報だけを差し出す公的集団。（ch000-sc10）
- **True self:** 個人内面としての「真の自己」は、この資料では分離不能である。ただし、集団としては**服従的かつ実務優先**の性格が前面に出る。（ch000-sc10）
- **Internal contradictions:** 個性の薄い匿名的な集団に見える一方で、その短い一言が**後続の『富士』命名譚への接続点**を担っており、物語機能としては重要である。（ch000-sc10）

### 2.5 Cognitive Patterns
問いを受けると、まず**具体的・地理的な対象へ変換して答える**傾向がある。（ch000-sc10）
判断は私見の開陳よりも、**帝の意図に沿う実際的回答**を優先する。（ch000-sc10）
思考の出力形式は長広舌ではなく、**短く、確定的で、奏上向き**である。（ch000-sc10）

## 3. Voice & Language

### 3.1 Overall Register
全体として、**奏上らしい簡潔で公的な言い方**を用いる。（ch000-sc10）
語り口は古風で、宮廷的な敬語運用を伴い、情緒よりも公的伝達を優先する。（ch000-sc10）

### 3.2 Catchphrases & Signature Expressions
- **「なむ」**：断定・提示の響きを持つ古風な言い回しとして確認できる。（ch000-sc10）
- **「侍る」**：臣下としての丁重さを帯びた結びとして確認できる。（ch000-sc10）
- **「駿河の國にある山」**：問いに対し、対象を端的に名指す代表的な応答句。（ch000-sc10）

### 3.3 Sentence Style Preferences
文は短く、**対象提示→補足説明**の順で組み立てられる。（ch000-sc10）
観測された発話でも、まず「駿河の國にある山」と対象を示し、その後に「この都も近く、天も近く侍る」と理由づけを添える。（ch000-sc10）
修辞の華やかさより、**判断の通りやすさ**が優先される。（ch000-sc10）

### 3.4 Humor Style
ユーモア使用は確認されない。（ch000-sc10）
少なくとも観測場面では、笑い・皮肉・戯れは挟まず、厳粛な朝議の空気を保つ。（ch000-sc10）

### 3.5 Language Under Emotional Intensity
緊張の高い帝前の場でも、言葉は崩れず**厳粛・服従的**である。（ch000-sc10）
感情が高まっても饒舌になるのではなく、むしろ**形式を守った簡潔さ**に寄るタイプとして描かれる。（ch000-sc10）
怒り・歓喜・悲嘆時の別口調は資料不足のため不明。
