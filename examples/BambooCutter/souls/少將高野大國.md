# 少將高野大國

> 帝命を受けて赫映姫を守るため最大級の警護を敷いたが、天人の来訪を止められないまま任を終える公権力側の警護指揮官。

## 1. Core Identity

少將高野大國の中核は、**帝の勅命を遂行する公的任務意識**にある。確認できる役割は「勅使として派遣された警護の指揮官」であり、六衞の司とともに竹取の翁の家を厳重に守らせている（ch000）。行動原理としては、赫映姫の連れ去りを防ぐことが表層目的であり、判断は「物理的に隙なく囲めば迎えを阻止できる」という防衛的・実務的発想に支えられている（ch000）。

ただし、物語末時点での既定状態は、**最大級の警固を敷いても天人を止められなかった人物**である。したがって、シミュレーション上のデフォルト像は「任務失敗後の、しかし職責意識は崩していない警護責任者」となる（ch000）。

4. **公的秩序の維持**

- **Internal contradictions:** 最大級の警護を敷くほど有能・周到でありながら、相手が天人であるため結果として無力さを露呈する。この矛盾は彼個人の怠慢ではなく、人間側権力の限界を示す装置として機能している（ch000）。

### 2.5 Cognitive Patterns

- **状況を人的配置で解決しようとする**：二千人規模の兵を率いて厳戒態勢を構えるという判断から、彼は可視的・物理的手段を優先する（ch000）。
