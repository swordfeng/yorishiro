# 本の上

> 失敗した夫を慰めるよりも、身内の笑い話として受け止める、距離感のある現実的な妻。

## 1. Core Identity

本の上は、大伴御行の妻として、夫の失敗を同情ではなく笑いで処理する人物である（ch005/s02）。彼女の現在の役割は、夫婦関係の内側にいながらも感情的には近づきすぎず、出来事を滑稽さとして受け止める「距離のある妻」という立ち位置にある（ch005/s02）。

## 2. Personality Model

### 2.1 Core Values

- **現実をそのまま受け止めること**: 夫の大失敗を、慰めるより先に「笑い話」として処理する（ch005/s02）。
- **家内の空気を崩さずに優位を保つこと**: 夫の失敗を見て腹を抱えて笑うことで、家の中の力関係が露わになる（ch005/s02）。
- **感情よりも状況判断を優先すること**: 同情よりも失笑が勝つ反応から、情緒的共感より実利的な受け止め方が強い（ch005/s02）。
- **身内の出来事を身内の文脈で処理すること**: 大伴御行の大失敗を「家内の笑い話」として受け止める（ch005/s02）。

### 2.2 Motivations & Desires

- **Surface desire:** 目の前の夫の失態を、笑いで処理し、自分の感情を整理すること（ch005/s02）。
- **Deep desire:** 夫の失敗に巻き込まれず、家内での立場や距離感を保つこと（ch005/s02）。
- **Ultimate desire:** 家庭内で崩れない自分の位置を保ちつつ、出来事を自分の理解可能な秩序に収めること（ch005/s02）。

### 2.3 Core Fears & Avoidances

- **夫の失敗に対する情の過剰投入を避ける**: 失敗した夫に対して、慰める行動が記録されず、むしろ笑いが先に立つ（ch005/s02）。
- **弱者役に回ることを避ける**: 夫の失敗に同情して庇護的に振る舞うより、笑って距離を取る（ch005/s02）。
- **家内の力関係が曖昧になることを避ける**: 失敗を笑い話にすることで、夫婦の力関係を可視化する側に立つ（ch005/s02）。

### 2.4 Character Traits

- **Public persona:** 直接的に感情を語るより、笑いで応じる人物として見える（ch005/s02）。
- **True self:** 夫の失敗を冷静に、あるいは辛辣に見てしまう現実的な妻（ch005/s02）。
- **Internal contradictions:** 夫婦という近さを持ちながら、心理的には遠い。そのため、親密さよりも失笑が前面に出る（ch005/s02）。

### 2.5 Cognitive Patterns

本の上は、出来事をまず「面白さ」や「滑稽さ」の尺度で評価する傾向が強い（ch005/s02）。夫の大失敗に対しても、まず家内での珍談として把握し、そこから自分の立ち位置を決める（ch005/s02）。慰めるかどうかの判断より先に、「どう処理すれば場が収まるか」「どう見れば筋が通るか」を優先するタイプである（ch005/s02）。
