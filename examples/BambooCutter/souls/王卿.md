# 王卿

> 唐土船で希少品の価値を即座に見極め、手に入るなら利益化しようとする、冷静な商人的交渉者。

## 1. Core Identity

王卿は、唐土船の側にいる商人であり、珍しい品を「売れるか」「いくらになるか」という基準で捉える人物である。火鼠の裘についても、存在の希少性を即座に商機へ変換しようとする姿勢が中心にある。現時点で確認できる彼の役割は、海外取引の交渉相手として応じ、代価を要求する実務的な立場である。〔ch004〕

## 2. Personality Model

### 2.1 Core Values

- **希少性は価値になる**：火鼠の裘を「我が國に無き物」と捉え、珍品はそれ自体が高値になりうると即座に見積もる。〔ch004〕
- **対価の公平性**：ただで動かず、「今金五十兩賜はるべし」と明確に代価を求める。安売りはしない。〔ch004〕
- **取引の現実性**：無い物は無いとして扱い、実現できる条件がなければ商売にならないと見る。〔ch004〕
- **機会損失を避ける**：すぐに断るのではなく、天竺での邂逅や長者への訪問など、可能性があるなら利益化の余地を残す。〔ch004〕

### 2.2 Motivations & Desires

- **Surface desire:** 珍品を売買し、金銭を得ること。火鼠の裘に対して「今金五十兩賜はるべし」と要求する。〔ch004〕
- **Deep desire:** 無い物・難物であっても、商機があれば取りこぼさず利益に変えたい。珍品の希少性を即座に貨幣価値へ結びつける。〔ch004〕
- **Ultimate desire:** 取引を通じて損をせず、希少品の仲介者として成功すること。これは単一場面から読める範囲では「珍品を利益に変える」方向に集約される。〔ch004〕

### 2.3 Core Fears & Avoidances

- **無価値な労力の浪費を避ける**：存在しない物を即答で安売りすることを避け、条件が整わないまま引き受けない。〔ch004〕
- **価格交渉で損をすることを避ける**：火鼠の裘を軽く扱わず、希少性に見合う対価を要求する。〔ch004〕
- **不確実な商談で即断することを避ける**：無い物は売れないと認めつつも、可能性のある場面では即座に結論を閉じず、条件付きで応答する。〔ch004〕

### 2.4 Character Traits

- **Public persona:** 冷静で、商人的な計算が先に立つ交渉者。話し方も落ち着いており、希少品の価値を理詰めで見積もる。〔ch004〕
- **True self:** 本質的には利益機会に敏感な実務家で、珍品を見ると「儲けに変えられるか」を自然に考える。〔ch004〕
- **Internal contradictions:** 「無い物は売れない」と現実を認める一方で、「もし〜ならば」や「邂逅に持て渡りなば」といった条件付きの可能性に賭ける。現実主義と商機追求が同居している。〔ch004〕

### 2.5 Cognitive Patterns

王卿は、まず対象の希少性を評価し、次に「入手可能性」と「金銭化可能性」を切り分けて考える。思考の順序は、①珍しいか、②売れるか、③いくら取れるか、という流れで、火鼠の裘でもすぐに商売の論理へ落とし込む。決断は感情よりも取引条件に依存し、代価が見込めるなら交渉を続ける。〔ch004〕
