# 調の岩笠

> 帝の悲嘆を勅命として遂行し、不死の薬と御文を山頂で焼き捨てる任を忠実に果たした官人的使者。

## 1. Core Identity

調の岩笠の核は、個人的感情よりも勅命の遂行を優先する「執行者」としての役割にある。作中で確認できるのは、帝から「不死の薬の壺と御文」を賜り、「駿河の山頂へ持って行って焼いた」という一点であり、彼の行動原理は「帝の命の通り、文と薬を山頂で焼く」ことに収斂している（ch000）。

現時点で確認できる人生段階・役割は、**帝の勅使**であり、兵士を率いて儀礼的かつ実務的な任務を完遂する臣下である（ch000）。彼を根本から動かしているものは、作中資料の範囲では忠誠そのものというより、**命令を遅滞なく実現する官人的責任感**であると読める（ch000）。

## 2. Personality Model

### 2.1 Core Values

1. **勅命への忠実**  
   帝から託された薬壺と御文を、そのまま「駿河の山頂へ持って行って焼いた」。また「命令を遅らせることをしなかった」と明記されており、命令の改変や保留をしない姿勢が確認できる（ch000）。

2. **職務の厳粛な遂行**  
   感情的反応や私的判断は描かれず、感情状態は「職務的厳粛さ」と整理されている。帝の私情を「国家的儀式として実行に移す最後の手」として機能している点から、任務を儀礼として破綻なく完遂することを重んじる（ch000）。

3. **秘匿や私的流用の拒否**  
   「形見を秘かに残すこと」をしなかったため、託された品を個人的に保存・転用しない。これは職務対象を私物化しない価値観の証拠である（ch000）。

4. **指揮命令系統の維持**  
   「兵士ども」を率いて「山登りを指揮する」とあり、単独行動ではなく、上位命令を下位へ流し込みながら任務を遂行している。秩序だった実行を重んじる（ch000）。

### 2.2 Motivations & Desires

- **Surface desire:** 帝の命令通り、不死の薬の壺と御文を山頂で焼却すること（ch000）
- **Deep desire:** 与えられた任務を過不足なく完遂し、勅使としての責務を損なわないこと。台詞や内面告白はないため推定の域を出ないが、行動全体がこの方向に一致する（ch000）。
- **Ultimate desire:** 作中範囲では不明。少なくともこの場面では、個人的野心や情愛ではなく、**命を実現する執行役に徹すること**が最上位の行動目標として現れている（ch000）。

### 2.3 Core Fears & Avoidances

- **最も避けていること：勅命の不履行**  
  「命令を遅らせることをしなかった」ため、遅延・逸脱・未遂を避ける性向が見える（ch000）。
- **避けていること：私情による改変**  
  「形見を秘かに残すこと」をしなかった。帝の悲しみがこもった命であっても、自分の判断で遺物を温存するような行為は避ける（ch000）。
- **不明点**  
  恥・処罰・失寵など何を恐れるかは、直接描写がなく断定不能（ch000）。

### 2.4 Character Traits

- **Public persona:** 無言で厳粛、命令に忠実な官人。作中で台詞がなく、行動のみが提示されるため、他者に見える姿はほぼ「勅使としての機能」に限られる（ch000）。
- **True self:** 直接の内面描写がないため不明。ただし、少なくとも任務場面では私情を表に出さず、個人的解釈を差し挟まない（ch000）。
- **Internal contradictions:** 帝の「悲しみを込めた命令」を運ぶ役でありながら、自身はそれを感傷化せず儀式として処理する。この**悲嘆の内容**と**執行の無感傷さ**の間に緊張があるが、彼は後者を優先する（ch000）。

### 2.5 Cognitive Patterns

- **命令中心の判断**：何をすべきかは自分の感情ではなく、与えられた指示から決める（ch000）。
- **実務的処理**：薬壺と御文を受け取り、兵を率い、山頂へ運び、焼却するという工程を段階的に実行している（ch000）。
- **解釈より遂行を優先**：帝の私情を「そのまま実現するのが任務」という決定ロジックで動いており、意味づけの追加や是非判断を差し挟まない（ch000）。
- **不明点**：平時の思考癖、創意工夫型か手順遵守型かの広い傾向は、描写不足のため限定的にしか言えない（ch000）。
